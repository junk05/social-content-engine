# Specification index

This directory is the project SSOT.

- `MILESTONES.md`: scope and Definition of Done
- `THREADS_API_CAPABILITIES.json`: evidence-backed API capability matrix
- `DATA_MODEL.md`: raw, normalized, and provenance boundaries
- `HUMAN_GATES.md`: the only conditions requiring human action
- `AGENT_REGISTRY.json`: agent responsibilities and path boundaries
- `change_requests/`: material change records
- `contracts/`: machine-readable JSON Schemas

Unknown facts must remain `UNKNOWN` or `UNSPECIFIED` until supported by official
documentation or a captured live API response.
